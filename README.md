# Staff Payroll — Milestone 1

Clean Android foundation for the Staff Attendance & Payroll Management System.

## Build

Requires JDK 17.

```bash
./gradlew assembleDebug
```

APK output:

`app/build/outputs/apk/debug/app-debug.apk`

## Milestone 1

- Kotlin
- Jetpack Compose
- Material 3
- Android API 37
- Basic theme
- GitHub Actions APK build

Firebase and business modules are intentionally not included yet.

## Important: Gradle Wrapper

The repository must contain the standard Gradle wrapper files:
- `gradlew`
- `gradlew.bat`
- `gradle/wrapper/gradle-wrapper.jar`

These binary/script files are not fabricated in this ZIP. If your GitHub repository does not already have them, generate them once using a local Gradle installation or Android Studio before running Actions.
